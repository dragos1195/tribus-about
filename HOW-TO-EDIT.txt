GODPARENT SURPRISE - how to edit and deploy
==========================================

Edit the surprise
  - Open surprise.html in any text editor. Everything you may want to change is
    marked with an "EDIT ME" comment: the door, the episode title, the photo
    captions, the question, what the runaway "Nu" button says, the funny
    contract, the captions for the fireworks button and the Joey GIFs.
  - Photos: surprise/photo-front.jpg (serious, front) and
    surprise/photo-back.jpg (funny, back). The baby page uses
    surprise/photo-kids.jpg. Replace the files to change them.
    Portrait 4:5 looks best.
  - Joey GIFs come from GIPHY, so they need an internet connection. To swap one,
    open a GIF on giphy.com and copy the id (the last part of its link) into the
    JOEY list in surprise.html. If a GIF can't load, its box simply hides.

Your profile page (dragos.html)
  - Everything on it comes from the PROFILE block near the bottom of
    dragos.html: bio, the three stat tiles, the technologies (name, level 0-100,
    label, years, one line) and the "also comfortable with" chips.

What triggers what
  - On the last screen, the 🍼 button opens the sunny baby page. Its text and
    the baby GIFs behind the 🧸 button (BABY_GIFS) are marked EDIT ME.
  - The Friends theme (surprise/theme.mp3) starts with the door tap and loops.
    The 🔊 button bottom-left pauses it. Replace the file to change the song.
  - On index.html, tapping Lucia's card opens surprise.html.
  - Tapping Dragoș's card opens dragos.html, the serious profile page. Everything else on index.html looks and behaves like the real
    About page; the menu and other links go to the real wearetribus.com.

Deploy (any static host works, pick one)
  - Netlify Drop: go to app.netlify.com/drop and drag this whole folder in.
  - Vercel / Cloudflare Pages / GitHub Pages: upload this folder as-is,
    no build step. index.html is the entry page.

Use it as a phone app
  - manifest.webmanifest and sw.js let the site be added to the home screen.
    It then opens full screen, and the surprise and profile pages open inside
    the app. Links to the real wearetribus.com still open in a browser.

Notes
  - The pages carry "noindex" so search engines won't list the copy.
  - Nothing on these pages collects or sends any data.
